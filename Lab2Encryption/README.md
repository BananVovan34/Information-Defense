# Лабораторная работа 2 — AES-192

Вариант 5. C#, Windows Forms, .NET 8. Внешние пакеты не нужны.

## Запуск и проверка

1. Открыть `Lab2Encryption.sln` в Visual Studio, нажать F5.
2. Через «Обзор…» выбрать `examples/исходный.txt`.
3. Указать новое имя выходного файла, например `исходный.txt.aes192`.
4. Ввести любой учебный пароль и нажать «Зашифровать».
5. Выбрать созданный `.aes192` как исходный файл. Для результата указать новое имя, например `исходный_restored.txt`.
6. Ещё раз ввести тот же пароль и нажать «Расшифровать». После каждой операции поле пароля очищается.
7. Сравнить исходный и восстановленный файлы. Они должны совпадать побайтно.
8. Повторить расшифрование с другим паролем и новым именем результата: программа покажет ошибку и не создаст результат.

Исходный текстовый файл: от 32 до 4 194 304 байт включительно. Программа сохраняет точные байты, без смены кодировки и переводов строк. Размер зашифрованного файла немного больше из-за заголовка, дополнения и кода проверки целостности. Существующие файлы не перезаписываются.

## Что внутри

- `FileEncryptionService.cs` — обработка файлов и криптография.
- `Form1.cs` — действия кнопок и сообщения о результате.
- `Form1.Designer.cs` — элементы формы, доступные в дизайнере Visual Studio.
- AES-192-CBC, блок 128 бит, дополнение PKCS#7. Используется `System.Security.Cryptography`.
- PBKDF2-HMAC-SHA256, 210 000 итераций. На каждое шифрование генерируется новая случайная соль 16 байт. Из пароля выводятся 56 байт: 24 для AES и 32 для HMAC.
- IV длиной 16 байт также генерируется заново для каждого шифрования.
- HMAC-SHA256 проверяет заголовок и шифротекст **до расшифрования**. Ошибка проверки означает неверный пароль или повреждение файла; отличить эти случаи по HMAC невозможно.
- Пароль и ключи не записываются в файлы или настройки. Пароль временно находится в памяти при вводе и выполнении операции; управляемая строка C# не позволяет гарантированно стереть все её копии. Массивы с производными ключами и открытым текстом очищаются после использования.
- Соль и IV открыто хранятся в заголовке: это не секретные ключи. XOR для маскировки пароля не используется.

## Формат файла, версия 1

| Поле | Размер |
|---|---:|
| Сигнатура ASCII `L2AES192` | 8 байт |
| Версия `01` | 1 байт |
| Случайная соль PBKDF2 | 16 байт |
| Случайный IV AES-CBC | 16 байт |
| Шифротекст с PKCS#7 | кратен 16 байтам |
| HMAC-SHA256 всех предыдущих байтов | 32 байта |

Алгоритмы и число итераций фиксированы для версии 1. Изменение этих параметров потребует новой версии формата. Программа расшифровывает собственный формат `.aes192`; произвольные файлы AES из других утилит не поддерживаются.
